# Contribuer

1. Forkez, créez une branche, ouvrez une Pull Request.
2. Une contribution = des lignes dans `donnees/` (traductions, glossaire). Lancez `python outils/ascension_fr.py verifier …` avant de proposer.
3. Respectez `docs/GUIDE_STYLE.md` (vouvoiement, jetons intacts, majuscule initiale seule pour les noms de sorts).
4. N'ajoutez jamais de fichiers du jeu (`*.MPQ`, `*.dbc`), de dumps SQL du serveur ni de contenus tiers sans autorisation.
5. Signalez une erreur de traduction via *Issues* : ID du sort, texte actuel, correction proposée.
